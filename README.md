# Pasantes de Hook

¡Bienvenido/a! Este repositorio es tu punto de partida. Acá vas a encontrar lo que tenés que hacer cada día durante tus **5 días de pasantía (3 horas por día)**.

Hook fabrica balanzas y software para el campo: un sistema que ayuda a manejar los animales, los corrales, las dietas y los pesajes de un feedlot (un corral de engorde de ganado). Durante estos días vas a pasar de "usé Scratch" a "subí mi propio código a GitHub".

**No hace falta saber nada de antemano.** Este documento se lee de arriba hacia abajo, un paso a la vez. Si algo no sale en **10 minutos**, no te quedes trabado/a: avisale a Mauro.

## Cómo se trabaja

Cada día tiene su propia guía, con el tiempo de cada bloque. Abrí la de hoy y seguila de arriba hacia abajo. **Empezá por el [Día 1](dias/dia-01.md).** Todos los días están en la tabla [Los 5 días](#los-5-días).

## Glosario

| Palabra | Qué significa |
|---|---|
| **Repositorio (repo)** | Una carpeta de proyecto guardada con todo su historial |
| **Git** | El programa que registra los cambios |
| **GitHub** | El sitio web donde se guardan los repos |
| **Fork** | Tu copia personal de un repo ajeno |
| **Clonar** | Bajar un repo de internet a tu computadora |
| **Commit** | Guardar un cambio con un mensaje que lo explica |
| **Push** | Subir tus commits a GitHub |
| **Pull request** | Pedir que tus cambios se sumen al proyecto |
| **Terminal** | Ventana donde se escriben comandos |
